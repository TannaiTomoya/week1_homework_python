# week1_homework_python

スパルタキャンプ Python編 week1 の課題A〜Eです。
すべて `uv run ファイル名.py` で実行できます。

## 課題の一覧

| 課題 | ファイル | 内容 |
|---|---|---|
| A | a.py | 1〜40で、3の倍数と3がつく数を「スパルタ！」にする |
| B | b.py | 氏名と生年月日から運勢を出す |
| C | c.py | 1〜40の素数をリストにまとめて表示する |
| D | d.py | Fighterクラスを作り、悟空とベジータを戦わせる |
| E | e.py | 仕訳の向きチェッカー（自作問題） |

## 実行方法

```
uv run a.py
```

`a.py` の部分を、動かしたいファイル名に変えてください。

## 進め方

課題ごとに Issue を作り、次の流れで進めました。

1. Issue に「目的・完了条件・触るファイル」を書く
2. ブランチ `feature/homework` で実装する
3. 完了条件を自分で確かめてから、`Closes #番号` を付けてコミットする
4. PR #7 にまとめ、レビューを受けて修正し、マージする

## 課題Eについて

課題Eは、開発中の経理アプリ [torudake-app](https://github.com/TannaiTomoya/torudake-app) につながる問題として作りました。
勘定科目が「増えた／減った」ときに、借方・貸方のどちらに書くかを、規則で判定します。

## つまずいたこと → 次からこうする

- `range(2, 7)` は 2〜6 だった → 終わりの数は「入れたい数＋1」を書く
- 字下げが1段ずれて、結果が変わった → 「何ごとにくり返したいか」で深さを決める
- `while True:` が止まらなかった → `while` を書いたら、先に `break` の条件を書く
- `{ }` に中身を書いてしまった → 2人以上が使うメソッドでは、`self.` か `opponent.` から取り出す
